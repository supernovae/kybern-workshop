### Bounded training storage refusal: native fix
The training preflight treated an eight-step invocation as a request to write all checkpoints over 244,141 scheduled updates. The cold path and verified prepared-input reuse were both affected. [Model Lab PR #527](https://github.com/supernovae/model-lab/pull/527) limits that estimate to reachable checkpoint events from the verified resume step to the invocation stop. The full scientific schedule stays intact. This is a native fix for any recipe using a bounded stop, not an override for this experiment. It leaves positive data/retention headroom. All 13 focused storage/documentation tests passed; a separate review checked 30,000 cadence scenarios. Other training, hardware and resume issues are not thereby closed.
