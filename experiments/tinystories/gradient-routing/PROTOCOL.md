## Question and endpoints
Does the projection of next-token CE error through an untied linear head explain a reproducible part of the learning curve, or can effective optimizer steps, coordinate choice and target ambiguity explain the apparent loss? Separately ask whether a change helps at matched valid training targets and at matched total device time. A large residual alone answers neither.

H1 raw projection depends on aggregation, numerical rank and common-logit gauge; centered retention should pass a gauge stress test. H2 equal starting functions with distinct trainable factors induce different effective updates. H3 restricting only backbone feedback is different from changing forward rank. H4 previously invisible directions may influence later updates. H5 stochastic labels can produce large residual at the Bayes predictor. H6 economical routing might improve CE, but only if it beats an equally tuned ordinary head in tokens *and*, separately, in measured time.

**First training contrast:** C0 native dense versus C4 trainable identity factor, A=W0, B=I. C4 frozen identity is an implementation null, not a competing finalist. Registration of this contrast is motivated by the old full-width factorization penalty without seeing new treatment learning curves. Select C0/C2/C3 for a later allocation only if C4 leaves the mechanism unresolved. The original factored option uses different initialization; matching its spelling/rank is not an implementation null.

Primary learning endpoint: mean held-out next-token NLL at the same count of valid primary targets. Primary practical endpoint: CE at common cumulative device-time cap; baseline-only calibration may substitute a predeclared, plausibly reachable development CE threshold before any screening. Censor arms that never cross it. Fixed initialization tensors, token order, model width, clipping, loss mask, precision, token-indexed warmup/decay, evaluation protocol and seeds are shared for C0/C4. Record pre/post-clip gradients and realized AdamW steps rather than assuming their equality. No auxiliary targets or replay in either arm. Compare effective head update norm/cosine and trunk update at step 1. Baseline, frozen identity and trainable identity must match initial logits/CE/dH/dW_A to precision tolerance; frozen B cannot be in the optimizer. Function matching and update-size calibration are distinct tests. No optimizer reset in scratch arms. If continuing, symmetric resets or preserved matching state for all arms.

## Metric contract
For N valid targets, H is NxD, W is VxD, G=softmax(H W^T+b)-onehot(y). For masked hard CE with mean over valid targets, dH=GW/N, dW=G^T H/N, db=sum(G)/N. Include mask, actual global accumulated valid-count normalization, AMP scale and clipping in comparisons. A tied tensor's input-embedding gradient is additional. Probe post-final-normalization and label any pre-normalization Jacobian effects. For factorization, use effective A B; for a nonlinear head, do not interpret the last matrix as the local Jacobian.

For orthonormal numerical basis Q of columns of W, pooled retained energy E=sum||gQ||^2/sum||g||^2, residual norm=sqrt(1-E), visible norm=sqrt(E). Distinguish per-token ratios, weighted counts/quantiles and zero-denominator exclusions. Pooled cos(G,GP)=sqrt(E); it is not an independent predictor. Never build VxV. Center W over vocabulary rows for the gauge-invariant measure; environment-common shift W+1a^T does not change the probabilities/CE/dH. Independent random-subspace expected energy r/V raw and r/(V-1) centered. An orthogonal projection is not singular-value-weighted feedback W W^T g and neither is the parameter update. A fitted training-A basis on disjoint training-B stories is not an oracle on B; only large N>>r in-sample rank-r SVD is an in-sample bound. Avoid estimates adapted on dev or test. Full BPB across tokenizers requires summed token NLL /(ln(2) times summed original UTF-8 bytes) on identical whole stories with explicit boundaries.
