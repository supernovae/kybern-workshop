## What we learned
The size of a vocabulary residual is not a measure of lost learning. In the known-distribution experiment below, two tasks had precisely the same residual energy while differing substantially in reducible error. In a different test using **actual TinyStories checkpoints**, residuals initially invisible to the backbone later aligned with the evolved output head more than an isotropic drift null would predict. A predeclared follow-up found that a uniform predictor with the same target counts reproduces 99.95% of the excess over the drift null. For this early checkpoint, the observation mostly describes which vocabulary rows moved. At maturity, pairing mattered relative to a shuffle, but the contrast with a uniform predictor remained too uncertain to justify a training intervention. Neither result demonstrates useful recycling of error.

**Token, compute and inference efficiency:** No inferred gains from any of these results. No time-to-quality target observed, no measured joules and no trained TinyStories C4 effect size. A null-subspace projection is an immediate linear statement; ordinary head updates can still use the same residual. Multiple gradients are not independent information channels.

## What to test next, ranked
1. **Train the function-matched ordinary C0 and full-width identity C4.** This directly tests whether a full-rank parameterization changes held-out learning after an identical start, where the historical experiment found a gap without matching initialization. On the authentic 32k recipe, calibrate each arm on the actual AMD backend, budget a common horizon with post-warmup updates, and reserve three fresh pairs before the screen. Separate evaluation at matched targets from matched elapsed time. The [conditional full campaign budget](CAMPAIGN-PROPOSAL.json) includes acquisition, calibration, screen, fresh confirmation, and a stopping rule if the budget cannot carry all of them. The 512-update option is a labeled pilot, not a one-pass replication.
2. **Only if C4 exposes a material learning gap, test matched realized head updates with symmetric LR tuning.** The one-step controls establish a mechanism by which a gap could arise, not that it caused the long-run penalty. Compare the proposed norm calibration with an equally tuned ordinary head; report angles, clipping and trunk updates. This requires its own budget; no extra optimizer variant is hidden in the proposed C0/C4 screen.
3. **Test temporal reuse on an independent mature checkpoint lineage only if already available cheaply.** The original early excess was explainable by target mix; at maturity two of three preregistered discrimination criteria passed. The paired-story interval still includes zero. Treat the observed permutation result as a reason to seek independent contexts or runs, not to train a new head-only/trunk-only/combined intervention. No M2 GPU priority on the present evidence.

## Draft public abstract (not posted)
We examined when the output head of a language model makes next-token error invisible to the current hidden-state update. We separated residual norm, squared energy, predictable residual error and changes in the head over time. On a synthetic process, orthogonal residual energy was identical for predictable and stochastic aliases, although reducible error differed. In one archived TinyStories run, the evolved head captured 0.377% of an initially invisible centered residual, above a 0.085% matched-drift expectation on 128 training contexts. A uniform-predictor control with the same target counts reproduced nearly all of that excess, weakening a contextual-reuse interpretation. Full-width factorization controls also showed that equal starting logits need not produce identical AdamW updates. At a mature checkpoint pair, true context-target pairing exceeded all 999 target permutations, but the paired 95% story interval for its difference from a uniform predictor crossed zero. We therefore did not promote a temporal intervention. The next controlled training test is dense versus an identity-initialized full-width factorization, not a claim of recovered learning or faster convergence.
