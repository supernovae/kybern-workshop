# Project Scope & Historical Archive

Kybern Workshop has three active experiment tracks you can inspect, repeat, and build on with [Kybern Model Lab](https://github.com/supernovae/model-lab):

1. **[Basic Synthetic CPU](../examples/synthetic-cpu/README.md)** — A fast offline run that checks your install, data preparation, training loop, and reporting.
2. **[TinyStories](../experiments/tinystories/README.md)** — A 58.9M base model and a preregistered [LM-head experiment](../experiments/tinystories/lm-head-bottleneck/README.md), with a [CPU microlab](../examples/tinystories-microlab/README.md). Earlier TinyStories recipes and results are in Git history at [`884eae8`](https://github.com/supernovae/kybern-workshop/tree/884eae8).
3. **[Devmind](../experiments/devmind/README.md)** — A 730M development-leaning model defined end to end: corpus, pretraining and post-training. The earlier 340M model and its campaign notes are in Git history at [`5f77dc2`](https://github.com/supernovae/kybern-workshop/tree/5f77dc2/experiments).

## Planned Research & Earlier Archive

Our research plans, covering conditional memory, fact swaps, context overrides, and dense-model controls, are on **[kybern.dev/experiments](https://kybern.dev/experiments/#planned-experiments)**. Each new study starts fresh on the current Kybern Model Lab.

We removed earlier exploratory studies and old experiment scaffolds from the main branch to keep the repository easy to navigate. You can still find their files in Git history at snapshot [`fd259e2`](https://github.com/supernovae/kybern-workshop/tree/fd259e2cad4e9856d6d659e8df34728a98b32502/).
